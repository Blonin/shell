# Création d'un shell en C

## Compilation

Pour compiler utiliser la commande suivante :
+ gcc -o shell shell.c 

Puis ./shell pour lancer le programme

## Remarque

Il s'agit d'un petit projet avec la possibilité de l'agrandir en ajoutant plus de fonction

Pour approfondir creuser
+ man 3p sur les syscall
+ POSIX section 13
